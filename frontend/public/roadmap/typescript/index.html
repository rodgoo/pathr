Roadmap para aprender TypeScript

TypeScript é JavaScript com tipos — e virou quase obrigatório em vagas. Mas só faz sentido depois de um JavaScript sólido.

Criar meu plano de estudos grátis

Primeiro, JavaScript de verdade

TypeScript não substitui aprender JavaScript; ele adiciona uma camada. Sem a base, os tipos viram ruído em vez de ajuda.

Tipos, interfaces e uniões

Anotar o que uma variável ou função aceita e devolve. É o que pega erro antes de o código rodar, no editor.

Generics e tipos utilitários

Escrever código que funciona com vários tipos sem perder a checagem. O que separa o TypeScript básico do profissional.

TypeScript com React ou Node

Onde ele brilha: componentes tipados no front, APIs tipadas no back. É assim que as vagas usam TypeScript de verdade.

Perguntas frequentes

Preciso saber JavaScript antes de TypeScript?

Sim. TypeScript é uma camada sobre JavaScript. Aprender os dois ao mesmo tempo costuma confundir; base de JS primeiro.

TypeScript é obrigatório para conseguir emprego?

Cada vez mais pedido, principalmente em React e Node. Não é obrigatório em toda vaga, mas domina o mercado moderno de front-end.

TypeScript é difícil?

A sintaxe extra é pequena; a dificuldade real é entender os tipos, e isso vem com prática. Quem já sabe JavaScript pega o básico em poucas semanas.
