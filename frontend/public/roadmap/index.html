Roadmaps por tecnologia

O que estudar, na ordem certa, para cada tecnologia: Java, Python, JavaScript, TypeScript, React, Node.js, DevOps e ciência de dados.

Criar meu plano de estudos grátis
Roadmap para desenvolvedor JavaA ordem para aprender Java de verdade: fundamentos, orientação a objetos, Spring Boot, banco de dados, testes e o que as vagas realmente pedem. Roadmap para desenvolvedor ReactA ordem para aprender React de verdade: HTML, CSS e JavaScript primeiro, depois componentes, hooks, estado, rotas e o que as vagas de front-end pedem. Roadmap para desenvolvedor PythonA ordem para aprender Python de verdade: fundamentos, estruturas de dados, um caminho (web, dados ou automação), banco de dados e testes. Roadmap para desenvolvedor JavaScriptA ordem para aprender JavaScript de verdade: fundamentos, o DOM, código assíncrono, um framework como React e Node.js no back-end. Roadmap para aprender TypeScriptPor que TypeScript virou padrão, e o caminho: JavaScript sólido primeiro, tipos, interfaces, generics e uso com React ou Node. Roadmap para desenvolvedor Node.jsA ordem para aprender back-end com Node.js: JavaScript sólido, um framework (Express ou NestJS), APIs REST, banco de dados, autenticação e testes. Roadmap para ciência de dadosO caminho para entrar em dados: Python, estatística e SQL, manipulação com pandas, visualização e uma base de machine learning. Roadmap para DevOpsO caminho para DevOps: Linux e redes, Git e CI/CD, Docker e contêineres, nuvem e infraestrutura como código — na ordem certa.
