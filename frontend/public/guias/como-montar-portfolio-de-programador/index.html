Como montar um portfólio de programador

O portfólio é o que prova que você programa — mais que qualquer certificado. Veja como montar um que abre porta, não um que passa despercebido.

Criar meu plano de estudos grátis

Poucos projetos, bem feitos

Dois ou três projetos completos, que você saiba explicar por inteiro, valem mais que dez pela metade. Domínio acima de quantidade.

Projetos que resolvem algo real

Um clone de tutorial impressiona pouco. Um projeto que resolve um problema seu ou de alguém — mesmo simples — mostra que você pensa como quem constrói produto.

Como apresentar cada projeto

Para cada um: o que faz, quais tecnologias, um link para rodar e o código no GitHub. Um README claro conta tanto quanto o código.

GitHub e LinkedIn

Deixe o GitHub organizado (READMEs, commits que fazem sentido) e o LinkedIn atualizado com os projetos. É onde o recrutador vai olhar.

Perguntas frequentes

Quantos projetos preciso no portfólio?

Dois ou três bem feitos e explicáveis. O recrutador prefere profundidade em poucos a superficialidade em muitos.

Projeto de tutorial conta no portfólio?

Conta pouco, porque não prova que você constrói sozinho. Vale como aprendizado, mas o portfólio brilha com projetos seus, mesmo que pequenos.

Preciso de projetos publicados na internet?

Ajuda muito ter um link para rodar (deploy), além do código no GitHub. Ver funcionando vale mais que só ler o código.

O PathR gera um roadmap de estudos a partir do seu currículo e objetivo, com biblioteca curada, quizzes, inglês corporativo, cursos com certificado e vagas que combinam com você. É gratuito.
