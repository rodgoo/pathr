Roadmap para desenvolvedor Flutter

Flutter faz um app rodar em Android e iOS a partir de um código só. Cresce rápido no mercado mobile, e o caminho é bem definido.

Criar meu plano de estudos grátis

A linguagem Dart

Flutter usa Dart. Sintaxe, tipos, funções e o básico assíncrono (Future/async) vêm antes dos widgets.

Widgets e layout

Tudo em Flutter é widget. Montar telas compondo widgets e entender o layout (Row, Column, Stack) é o coração da ferramenta.

Estado e navegação

Gerenciar o estado da tela (setState e um gerenciador como Provider ou Riverpod) e navegar entre telas. Onde o app começa a ganhar vida.

Consumir API e persistir dados

Buscar dados de um servidor e guardar informação no aparelho. É o que quase todo app real faz.

Publicar e o resto

Testes, Git e o processo de publicar nas lojas. Fecha o ciclo de um app de verdade.

Perguntas frequentes

Flutter ou React Native?

Flutter (Dart) tem desempenho muito bom e uma experiência de desenvolvimento consistente; React Native aproveita o JavaScript/React que você talvez já saiba. Os dois empregam — escolha pela base que já tem ou quer ter.

Preciso saber programar antes de Flutter?

Ajuda muito. Flutter assume lógica de programação; quem começa do zero absoluto costuma aprender os fundamentos (via Dart) junto, o que estica o caminho.

Flutter serve para web também?

Sim, roda em web e desktop além de mobile, mas o forte e o que mais tem vaga é o mobile — Android e iOS.
