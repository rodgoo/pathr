Roadmap para desenvolvedor JavaScript

JavaScript é a única linguagem que roda no navegador — e, com Node.js, também no servidor. Aprender bem abre front-end e back-end.

Criar meu plano de estudos grátis

Fundamentos da linguagem

Tipos, funções, arrays, objetos e escopo. A base que todo framework assume — e que, quando falta, faz o resto parecer mágica.

O DOM e eventos

Como o JavaScript mexe na página: selecionar elementos, reagir a cliques, mudar o conteúdo. É o que torna a web interativa.

Assíncrono: promises e async/await

Buscar dados de uma API sem travar a tela. É o assunto que mais confunde no começo e o que mais aparece no trabalho real.

Um framework de front-end (React)

Depois da base, um framework como React organiza apps grandes. Aqui o JavaScript vira produto.

Node.js no back-end

O mesmo JavaScript no servidor: APIs, banco de dados e a stack completa numa linguagem só.

Perguntas frequentes

Preciso aprender JavaScript antes de React?

Sim. React é JavaScript; a maior parte da dificuldade de quem 'não entende React' é JavaScript que faltou. Base primeiro.

JavaScript dá emprego?

Muito. É a linguagem da web: front-end (React, Vue, Angular) e back-end (Node.js). Uma das que mais têm vagas no mercado.

Vale aprender TypeScript depois?

Vale, e cedo. TypeScript é JavaScript com tipos e virou padrão em vagas. Comece com JS e adote TS quando a base fizer sentido.
